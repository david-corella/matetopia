## Español

### Descripción

Presentación visual sobre **astronomía y espacio** diseñada en Canva. El trabajo se centra en la
narrativa visual y el diseño de diapositivas para comunicar ideas complejas: jerarquía visual,
coherencia estética y síntesis de conceptos.
